# «Ордо» — сайт ресторана

Адаптивный многостраничный сайт на HTML, CSS и обычном JavaScript. Данные меню, новостей, галереи, событий и контактных настроек хранятся в JSON. Сервер, база данных и сборка проекта не нужны.

## Запуск в VS Code

1. Откройте папку проекта `ordo` в VS Code.
2. Установите расширение **Live Server**, если оно ещё не установлено.
3. Нажмите правой кнопкой по `index.html` и выберите **Open with Live Server**.

Открывайте сайт через локальный HTTP-адрес, который покажет Live Server. При запуске через `file://` браузер блокирует `fetch()` для JSON-файлов, поэтому динамические данные меню, новостей и галереи не загрузятся.

## Страницы

- `index.html` — главная страница.
- `menu.html` — поиск, категории, сортировка, избранное и карточки блюд.
- `banquets.html` — формирование заявки на мероприятие.
- `gallery.html` — фильтр фотографий и просмотр с клавиатуры или свайпом.
- `news.html` — новости с открытием полного текста.
- `achievements.html` — примеры событий и отзывов.
- `contacts.html` — контактные данные и заявка на бронирование.

## Как менять данные

- **Меню:** редактируйте `data/menu.json`. У каждой позиции укажите название, категорию, описание, состав, вес, цену и путь к фотографии из `assets/images/`. Цены демонстрационные, в сомах.
- **Новости:** добавьте или измените записи в массиве `news` файла `data/news.json`. Для новой фотографии положите файл в `assets/images/` и укажите его путь в JSON.
- **Галерея:** редактируйте массив `images` в `data/gallery.json`; доступные категории заданы в `categories`.
- **События и отзывы:** примеры для страницы событий находятся в `data/events.json`. Сейчас они помечены демонстрационными. Не публикуйте вымышленные события и отзывы как реальные.
- **Контакты и часы:** заполните `phone`, `whatsapp`, `instagram`, `address`, `mapUrl` и `workingHours` в `data/settings.json`. WhatsApp указывайте с кодом страны, например `996...`, без пробелов. Пустые контакты сайт обозначает как незаполненные.
- **Вместимость и условия:** редактируйте объект `capacity` и текст `note` в `data/settings.json`.

Все изображения в `assets/images/` созданы для демонстрационного макета и не являются фотографиями реального ресторана. Заменить фотографию можно, сохранив имя файла или обновив ссылку в соответствующем JSON/HTML. Логотип и орнамент лежат в `assets/icons/`.

## Бронирование

Форма проверяет обязательные поля, телефон, дату, время работы и число гостей, затем готовит сообщение для WhatsApp. Если номер WhatsApp не заполнен, текст заявки можно скопировать вручную. Заявка не подтверждается сайтом: бронь действует только после подтверждения сотрудником ресторана.

Интерактивные функции выполняются в браузере. Сервер нужен только для раздачи файлов и загрузки JSON; обработка и подтверждение бронирований на сервере не настроены.
